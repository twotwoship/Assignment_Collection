# ATmega128A 디지털시계·계산기

> DS1307 RTC 기반 시계 및 스택 기반 수식 계산기

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 개발 목적 | RTC·LCD·키패드를 연동한 시계·계산기 구현 |
| MCU | ATmega128A |
| 개발 언어 | C |
| 주요 기술 | I²C, FSM, Timer Interrupt, Stack |
| 입력 장치 | 4×4 Matrix Keypad, Push Button |
| 출력 장치 | LCD1602 |
| 시계 모듈 | DS1307 RTC |

## 3. 주요 구현

| 구분 | 구현 내용 |
|---|---|
| 시계 | RTC 날짜·시간 읽기 및 LCD 출력 |
| 시간 설정 | 버튼 입력 기반 날짜·시간 수정 및 RTC 저장 |
| 계산기 | 키패드 기반 숫자·연산자 입력 및 결과 표시 |
| 수식 처리 | 중위표기식 → 후위표기식 변환 |
| 연산 | 스택 기반 사칙연산·괄호·우선순위 처리 |
| 상태 관리 | 시계·설정·계산기 모드 전환 |
| 입력 처리 | 타이머 인터럽트 기반 버튼 이벤트·키패드 스캔 플래그 |
| 데이터 변환 | RTC 데이터의 BCD ↔ 10진수 변환 |

## 4. 동작 모드

| 모드 | 주요 동작 |
|---|---|
| 시계 모드 | 날짜·시간 표시 및 주기적 화면 갱신 |
| 설정 모드 | 설정 항목 선택·값 변경·RTC 반영 |
| 계산기 모드 | 수식 입력·편집·계산 결과 출력 |

**시계 처리**

RTC 데이터 읽기 → BCD 변환 → 날짜·시간 구성 → LCD 출력

**계산기 처리**

키패드 입력 → 수식 저장 → 후위표기식 변환 → 스택 연산 → LCD 출력

## 6. 설계 의도

- **상태 관리:** 함수 포인터 배열 기반 모드별 처리
- **입력 이벤트:** 인터럽트에서 플래그 생성, 모드 처리에서 확인
- **화면 갱신:** 타이머 카운터 기반 주기적 갱신
- **RTC 통신:** I²C START·STOP·송수신·ACK/NACK 처리
- **수식 계산:** 연산자 스택·숫자 스택 분리
